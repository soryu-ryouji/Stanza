# Stanza

[Stanza 纯文本任务管理格式](https://github.com/Ryougi-Shiki0/Stanza) 的 Windows 桌面编辑器。极简设计，结构化查看与编辑 `.stanza` 文件。

## 构建与运行

```bash
dotnet build
dotnet run --project src/Stanza.App            # 启动
dotnet run --project src/Stanza.App -- TODO.stanza   # 启动并打开文件
dotnet test                                    # 运行解析器测试
```

要求：.NET 10 SDK 或更高版本，Windows。

## 使用

| 操作 | 方式 |
| --- | --- |
| 打开文件 | 拖入窗口 / `Ctrl+O` / 命令行参数；启动时自动恢复上次文件 |
| 最近文件 | `Ctrl+R` 打开菜单并高亮下一个文件（首行是当前文件，快速一开一松即切换到上一文件），重复按 `R` 循环下移，松开 `Ctrl` 打开高亮项；`Esc` 取消 |
| 切换最近文件 | 悬停左下角区域，点击列表项；`×` 从列表移除 |
| 新建文件 | `Ctrl+Shift+N` |
| 键盘模式 | 设置面板可选 Windows / macOS：macOS 模式下 Alt 扮演 Command——应用快捷键（保存/打开/新建/最近文件/撤销等）与文本复制键（复制/剪切/粘贴/全选/撤销）整体迁到 Alt，Ctrl 专作文本编辑移动键，原生 Ctrl 复制键禁用；Windows 模式相反（文本编辑移动键在 Alt）。下表手势以 Windows 模式为准 |
| 保存 | `Ctrl+S`；输入停止约 1.2 秒后自动保存 |
| 新建任务 | `Ctrl+N` 或底部工具栏按钮（追加到区块末尾） |
| 指定位置新建 | 新建后拖拽调整位置 |
| 选中任务 | 单击（高亮指示条）；方向键或 vim 键位 `hjkl` 移动选择（`j`/`k` 上下移动），文本框内为正常输入不参与导航；`Shift+方向键` 从当前选中扩展批量选中（支持多选批量操作） |
| 编辑任务 | 快速双击展开；`Enter` 展开选中项；`Ctrl+Enter` / `Esc` / 点击空白处确认收起（备注栏内 `Enter` 为换行）；未填写的空草稿在失焦（含切换区块、点击其他任务）时自动移除 |
| 文本框编辑键 | Windows：`Alt+A/E` 行首/行尾、`Alt+B/F` 左/右移一字符、`Alt+N/P` 下/上移一行、`Alt+D/H` 前删/回删一字符、`Alt+K` 删至行尾；macOS 模式同键位在 Ctrl（此时复制/粘贴/全选/撤销在 Alt+C/V/X/A/Z）。文本框内优先于应用快捷键 |
| 备注列表续接 | 行首为 `- `、`- [ ] `、`1. ` 时按 `Enter` 自动补全下一项记号（复选框重置未勾、序号递增、缩进保留）；记号后无内容时再按 `Enter` 清除记号退出列表 |
| 删除任务 | `Backspace` 移入 DELETE（回收站）；`Delete` 彻底删除（任意区块，支持多选） |
| 填写属性 | 展开后在主行内联书写：`YYYY-MM-DD` 截止、`+项目`、`#标签`；优先级不在文本中展示（见下行） |
| 设置优先级 | 右键任务卡片「优先级」：四象限（A–D）可选，可清除；标题按象限着色（A 红 → D 淡灰）。直接输入 `(A)` 前缀也会被自动接管为结构化优先级 |
| 标签/项目选择器 | 选中任务后按 `T`（标签）/ `P`（项目），或右键任务卡片「标签…」「项目…」：弹层顶部输入框可过滤列表，输入不存在的名称按 Enter 新建并应用（名称按 RFC §7.2.4/§7.2.5 校验）；列表 ✓ 为选中任务当前已拥有，标签点击切换（全部拥有则移除，否则添加）、项目点击设置；底部「清除」仅在选中任务已有该类内容时出现。支持多选批量 |
| 选择器键盘操作 | `↑↓` / `Alt+J/K` / `Alt+N/P` 移动高亮行；`Space` 选择（标签切换、面板保持打开可连续选择；项目应用并关闭）；`Enter` 确认（标签直接关闭、项目应用高亮项；无高亮时提交输入文本）；`Esc` 关闭；直接输入字符即过滤，焦点始终在输入框 |
| 自定义快捷键 | 左下角「设置」→ 快捷键：点击 `+` 录制新键位，`×` 删除，「重置」恢复默认。应用级快捷键（保存/打开等）须含修饰键；任务操作键（完成/面板/导航/删除等）支持裸键。配置存于 `%APPDATA%/Stanza/keymap.json`，右键菜单的快捷键提示随改动更新 |
| 排序 | 按住卡片拖拽，实时预览落点 |
| 移动到其他区块 | 拖拽卡片到侧栏区块上松手；或右键菜单选择 |
| 切换区块 | 侧栏点击 / `Alt+1~4` |
| 完成任务 | 点击任务前的勾选框（渐变消失动画后进入 DONE）；或选中后按 `Space` |
| 撤销 | `Ctrl+Z` 撤销上一步操作（流转/删除/新建/编辑/拖拽/清空等）；编辑框内为文本级撤销 |
| 清空 DONE / DELETE | 底部工具栏「清空」（二次确认后生效） |
| 任务操作 | 右键任务卡片：完成 / 移到 WAIT / 移到 DOING / 优先级 / 标签… / 项目… / 废弃 / 恢复 / 彻底删除（按状态显示） |
| 完成 / 废弃 / 恢复 / 彻底删除 | 展开卡片底部的操作按钮 |

## 行为说明

- 解析与写回遵循 Stanza RFC 1.5.0：四状态区块、主行元数据、缩进续行、时间戳行（创建/完成）等规则全部实现并有测试覆盖。
- 创建/完成时间戳是任务属性：以标签（chip）形式展示在任务详情中，不混入备注编辑器；保存时集中在主行之后的属性块中，与备注分离（§7.4.3）。
- 备注为纯文本多行编辑，空内容时以水印提示；折叠卡片只显示一个备注标记，列表保持紧凑。
- 「完成」（勾选框或按钮）会将任务移至 DONE 顶部、移除优先级并在属性块末尾追加完成时间戳行（RFC §9 / §7.4.3）；「废弃」移至 DELETE 顶部；「恢复」移回 DOING 末尾；新建任务自动写入创建时间戳行。
- 退出时如有未保存更改，弹出应用内确认层：保存并退出 / 不保存退出 / 取消（`Enter` 保存，`Esc` 取消）。
- 保存为规范化输出：UTF-8（无 BOM）、LF、区块标题大写、按 DOING / WAIT / DONE / DELETE 顺序、任务间空行分隔。
- DOING / WAIT 始终自动按（优先级象限 → 截止日期）稳定排序，无需手动操作；同优先级内的相对顺序可用拖拽调整。
- 备注在编辑器中顶格显示，保存时统一为 4 空格缩进。
