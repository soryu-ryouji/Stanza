# Stanza RFC

Stanza 纯文本任务管理格式的规范仓库。

## 什么是 Stanza

Stanza 是一种受 [TODO.txt](http://todotxt.org/) 启发的纯文本任务管理格式。整个任务列表存放在一个 UTF-8 纯文本文件中，通过**状态区块**划分任务生命周期，通过**段落式任务**承载结构化元数据与自由备注。名称取自诗歌中的"节"（stanza），呼应其以段落组织任务的结构。

核心概念：

- **状态区块**：`# DOING`、`# WAIT`、`# DONE`、`# DELETE` 四种标题行把文件分成进行、等待、完成、回收站四个区域。
- **任务段落**：每条无缩进的非空白行开启一个新任务（换行即分隔）；其下的缩进行是该任务的备注续行，备注内允许空行。
- **主行元数据**：行首依次是可选的优先级 `(A)`–`(Z)`、截止日期 `YYYY-MM-DD`，描述主体中内嵌至多一个 `+项目` 和零至多个 `#标签`。
- **时间戳行**：续行中整行匹配 `YYYY-MM-DD + 关键字`（创建/完成，支持英文别名）的行，承载任务的创建与完成时间。

最小示例：

```stanza
# DOING

(A) 2026-08-07 完成登录模块的单元测试 +Apollo #紧急
    先跑通现有测试用例

# DONE

2026-08-05 修复列表页滚动卡顿 +Apollo
    2026-08-04 创建
    2026-08-06 已合入主干
    2026-08-06 完成
```

## 实现自己的解析器 / 工具

规范第 10 节为实现者准备了完整的参考材料：

- **词法规则**：可直接使用的正则表达式（含不支持 `\p{...}` 的引擎的近似写法）。
- **解析算法**：逐行处理的伪代码，正确处理"备注内空行""孤立续行""同状态区块合并"等情况。
- **边界测试用例**：20 组输入与期望解析结果的对照表。
- **AI 提示词模板**：可直接粘贴给 AI 生成解析器或插件。
